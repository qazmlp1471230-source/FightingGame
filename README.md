# 🎮 文字格斗游戏 (Fighting Game)

这是一个基于 Java SE 开发的控制台文字格斗游戏。

## 🛠️ 用到的技术
- **核心语言**：Java SE
- **设计思想**：面向对象（封装、继承、多态）、接口
- **数据结构**：集合框架 (ArrayList)
- **版本控制**：Git / GitHub

## 🚀 游戏功能
- 用户注册与登录（包含验证码校验、账号锁定功能）
- 属性点分配（生命值、攻击力、防御力）
- 回合制战斗（普攻、强力一击、生命汲取、敌人技能）
- 动态血量条展示

## 📂 运行方式
直接克隆代码到本地，使用 IDEA 运行 `src/net/gamicode/App.java` 即可。
